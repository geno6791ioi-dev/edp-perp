# EDP – PERP privacy policy

EDP – PERP is a private app used by one film team. It is not sold to the public.

**Google Drive.** When a film's creator links Google Drive, EDP asks Google only for the
"drive.file" permission: it can see, create and change only the files and folders EDP itself
makes, inside a folder named "EDP Projects" in the creator's own Drive. It never reads the rest
of the Drive.

**What is stored.** EDP keeps the Drive link (a token) on the team's own licence server so the
film's files can be synced between the creator's devices and, through the server, the teammates
the creator has invited. Each teammate sees only what their role in the film allows.

**What is not done.** Nothing from Google Drive is sold, shared with advertisers or used for
anything but syncing the film. The link can be removed at any time with "Unlink" inside the app;
the files stay in the creator's Drive.

EDP's use of information received from Google APIs follows the Google API Services User Data
Policy, including its Limited Use requirements.
